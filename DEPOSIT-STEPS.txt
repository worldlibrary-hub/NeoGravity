RELEASING A VERSION OF THE SUITE

This folder is the repository's contents. To release:

1. Commit the files, tag the commit with the version (v4.0), and publish the tag
   as a GitHub release.
2. If the repository is linked to Zenodo, the release mints a new version under
   the concept DOI 10.5281/zenodo.22087714 (which stays the citable identifier).
   If not linked, upload verify_neogravity.py, README.md, sample_output.txt and
   CITATION.cff to the existing Zenodo record as a NEW VERSION; do not create a
   new record.
3. Run before releasing:  python3 verify_neogravity.py   (exit 0; the output should
   match sample_output.txt apart from the timestamp, if any).

Requirements: Python 3, sympy, numpy (requirements.txt).
